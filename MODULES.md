# Module hardening queue

Rows are the keys of `moduleRegistry` in `packages/modules/src/registry.ts`, in dependency order.
Status: `todo` → `hardened` (tests green, reviewed, no open HIGH issues) → `shipped` (you tested it by hand).
`unbuilt` = in the registry but no code yet.

**Re-audited 2026-11-18.** Every row used to read `hardened` / "None", which was not true. `AUDIT.md` has the evidence
and a dated fix log.
No module is `hardened` until its open HIGH issues below are closed and its E2E specs pass under
`pnpm test:e2e --grep @<module>`. Specs were tagged on 2026-11-18, and chat, mail and whiteboards got their first specs
the same day. **Production** still needs migrations `0058`–`0082` before this code ships.
